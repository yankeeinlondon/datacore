# Datacore View: Vue

Scaffold for the `datacore-view-vue` Obsidian plugin (`@yankeeinlondon/datacore-view-vue`).

The authoring model (declarative blocks, render functions/JSX, SFC templates, or a phased mix) and its codeblock
language family are decided in [`features/2026-11-08-frontend/`](../../features/2026-11-08-frontend/). Until then this
package has no source or build. Constraints it must respect are listed in the Engine Room spec, §9.5.
